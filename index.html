About This Project

DGX Console is a browser-based simulator of an NVIDIA DGX data center fleet — H100, H200, B200, GB200, and VR200 nodes — built for exploring GPU cluster monitoring and command-line tooling (nvidia-smi, dcgmi, ipmitool, NVLink, and ConnectX/InfiniBand utilities) in a safe, consequence-free environment. Every GPU reading, sensor value, and command output is fabricated entirely in your browser — nothing here is connected to real hardware.

Security & Privacy

  • No accounts — there's nothing to sign up for or log into.
  • 100% client-side — every command, GPU reading, and diagnostic output is generated by JavaScript running in your browser; nothing is sent to a server.
  • No data collection — no analytics, no tracking, no cookies, no data of any kind is collected.
  • No backend — this is a single static page; there is no database, authentication service, or server-side component of any kind.
